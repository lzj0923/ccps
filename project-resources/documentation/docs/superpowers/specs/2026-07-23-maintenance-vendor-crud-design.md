# 修繕服務商管理設計

## 目標

在修繕報告頁提供「服務商管理」入口，讓管理員可在二級頁面新增、查看、修改及停用服務商，並讓修繕報告的服務商下拉選單即時使用最新名單。

## 使用流程

管理員進入「修繕報告」→ 點擊「服務商管理」→ 在二級頁面查看服務商列表 → 新增或修改資料；刪除採用停用，停用後不再出現在新修繕工單的選單，但歷史工單仍保留原服務商名稱。

## 資料欄位

- 服務商編號：系統自動產生，保持唯一。
- 服務商名稱：必填。
- 聯絡人、電話、Email：選填。
- 狀態：啟用或停用。

## 權限與資料安全

只有已登入的管理員可進入及操作；不做實體刪除，避免破壞已有維修、財務及審計資料。

## 錯誤處理與驗證

服務商名稱不可為空；編號不可重複；API 失敗時在頁面顯示錯誤，不清除使用者已輸入內容。完成新增或修改後重新載入列表及修繕頁的服務商選單。

## 驗證方式

前端建置通過；後端以現有測試框架驗證服務商查詢、新增、修改及停用接口的成功與錯誤情況。
