# 租赁合约读取房产交接清单设计

## 目标

生成租赁合约 PDF 时，使用该租约对应房产的启用交接清单项目，避免合约仍显示模板示例物品。

## 方案

- 后端按 `leaseId` 找到对应单位，并读取 `property_handover_checklist_items` 中启用的项目。
- 按房产清单的分类与排序生成第二附表 Inventory List，写入模板第 15–17 页。
- 数量使用房产清单的默认数量；入住和退租栏保持空白。
- 停用或删除的清单项目不进入新合约；其他条款、签署页、照片页及 PDF 页数保持不变。

## 验证

- PDF 服务测试确认启用项目出现在 Inventory List。
- PDF 服务测试确认停用项目不出现在 Inventory List。
- 重新打开生成的 PDF，检查页数和清单文字。
