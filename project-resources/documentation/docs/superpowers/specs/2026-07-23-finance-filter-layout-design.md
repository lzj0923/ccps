# 財務確認篩選列位置調整設計

## 目標

讓管理員先選擇財務類型，再立即看到該類型可用的搜尋與篩選條件，避免搜尋列位於類型切換上方而被誤認為與當前頁籤無關。

## 版面

財務確認主內容依序排列：

1. 財務類型切換：買房款、租金、預備金充值、房產費用。
2. 篩選工具列：關鍵字搜尋、建案、確認狀態。
3. 操作區：當前類型的確認按鈕、匯出與歷史記錄。
4. 資料表格與服務端分頁。

篩選工具列在桌面版保持單列；空間不足時允許換行，但搜尋框優先佔用剩餘寬度。切換財務類型後，搜尋提示文字及狀態選項繼續沿用現有的動態邏輯。

## 行為與資料

- 僅調整版面順序，不改變 API、搜尋條件、分頁、批量確認或歷史記錄功能。
- 現有關鍵字、建案、狀態和日期篩選仍由服務端執行。
- 切換類型及篩選條件時，仍重置到第一頁並重新查詢。

## 驗證

- 四個財務類型均能顯示篩選列。
- 搜尋與篩選請求參數保持不變。
- 確認、匯出與歷史記錄按鈕仍能正常觸發。
- 前端生產編譯通過。
