# 租赁授权委托书入口调整设计

## 目标

让授权委托书归属于“出租委托”业务，而不是“租客与租金”业务；租客与租金页面只保留 OTR 出价函入口。

## 方案

- 从 `AdminTenancyWorkspace` 移除授权委托书按钮。
- 在 `AdminRentalMandateWorkspace` 的已选委托详情操作区增加“生成授权委托书”按钮。
- 生成时使用当前出租委托的业主、物业/单位和委托起止日期，并沿用现有合同模板 API。
- 生成成功后仍由浏览器下载 PDF；委托文件归档继续使用现有附件管理，不新增数据库结构。

## 验收标准

1. 租客与租金页面不再显示授权委托书按钮，OTR 按钮仍可用。
2. 出租委托详情页显示授权委托书按钮，并且未选择委托时不显示。
3. 点击后能打开授权委托书生成弹窗，字段使用当前委托资料预填。
4. 简体、繁体、英文均使用 i18n 词条。
