# 管理员账号工具栏空白按钮

## 问题现象

进入“管理员账号”页面后，“新增管理员”右侧出现一个没有文字的黄色按钮。

## 复现方式

1. 使用有管理员账号管理权限的账号登录后台。
2. 进入“系统管理 > 管理员账号”。
3. 查看搜索栏右侧操作区，可看到一枚没有文案的黄色按钮。

## 根本原因

管理员账号模块没有配置次要操作文案，但通用工具栏只按模块类型判断是否显示次要按钮，没有判断最终文案是否为空，因此仍然渲染了空按钮。

## 修复内容

通用工具栏在渲染次要按钮前，新增“文案非空”校验。没有实际操作名称的模块不再显示该按钮；其他已配置次要操作的模块不受影响。

## 验证结果

- 管理员账号页面不再出现空白黄色按钮。
- 其他具有明确次要操作的页面仍正常显示按钮。
- 已增加自动化回归测试，防止空文案按钮再次出现。
