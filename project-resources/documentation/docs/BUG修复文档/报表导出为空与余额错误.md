# 报表导出为空与余额错误修复

## 问题现象

- “房款收款与未收款”在存在房款计划、但没有对应财务流水时，导出文件没有数据。
- “租金收款进度”同样只导出已登记的收款流水，无法完整展示未收、部分收和逾期账单。
- “收入与支出明细”和“业主账单”的逐笔余额方向相反，并且显示的是交易发生前的余额。

## 根因

- 房款和租金进度报表从 `finance_records` 财务流水表开始查询。未收款尚未形成财务流水，所以必然被遗漏。
- 逐笔余额使用了“支出减收入”的反向公式，并在计算当前交易前写入余额。

## 修复内容

- 房款报表改为从 `payment_installments` 房款分期计划读取，再按每期 `amount_due` 与 `amount_paid` 计算已收、部分收、未收和逾期状态。
- 租金进度报表改为从 `rent_invoices` 月度租金账单读取，完整导出应收、已收及未收情况。
- 逐笔余额改为“上一笔余额 + 收入 - 支出”，并显示当前交易完成后的余额。
- 同步更新报表页面说明，明确房款按到期日、租金按账单月份统计。

## 其他导出检查

- 维修费用：按维修工单读取，口径正常。
- 预备金余额及流水：按预备金异动读取，口径正常。
- 业主预备金返还：按返还财务记录读取，口径正常。
- 财务确认记录：按财务记录读取，口径正常。
- SQL Account 导出结果：按同步批次读取，口径正常。
- 单个租客账单：按租金账单读取，口径正常。
- 单个业主账单：共用收支明细，余额公式已一并修正。
