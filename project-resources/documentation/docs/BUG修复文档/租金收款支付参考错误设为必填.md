# 租金收款支付参考错误设为必填 - 修复报告

## BUG描述

- 页面/功能：租金确认收款、批量确认、收款记录编辑及管理员预备金充值。
- 操作步骤：付款方式选择银行转账等非现金方式，支付参考留空后提交。
- 期望结果：支付参考为可选补充资料，可以留空确认收款。
- 实际结果：前端阻止提交；绕过前端后，后端仍返回必填错误。

## 复现与根因

- 单笔确认、批量确认、房产详情编辑均写有非现金支付参考必填校验。
- 后端租金确认和收款编辑服务重复执行了相同限制。
- 新增回归测试后，修复前稳定返回 HTTP 400，问题已复现。

## 修复方案

- 删除租金收款前后端的非现金支付参考必填校验。
- 空内容统一保存为 `null`，有填写时仍正常保存。
- 界面字段明确标注“选填”，并保留银行流水号等填写提示。
- 不改变付款方式、金额、凭证、押金抵扣及入账规则。

## 单元测试与验证

- 银行转账支付参考留空时，单笔收款记录可修改。
- 银行转账支付参考留空时，批量租金确认可完成。
- 银行转账支付参考留空时，管理员预备金充值可完成。
- 后端相关测试通过，前端生产构建通过。

## 手动验证步骤

1. 打开财务确认中的租金账单。
2. 选择银行转账，支付参考留空。
3. 提交单笔确认，确认可正常入账。
4. 再对多笔账单执行批量确认，支付参考留空并确认成功。
