# 智慧大屏、管理总览、租房管理与侧边栏 i18n 不完整

## 问题现象

切换到繁体中文或英文后，智慧大屏、管理总览、租房流程、租客与租金，以及侧边栏“租客管理”仍有部分文字保持中文。

## 根因

近期新增的模板文字、脚本动态状态、统计卡片标题和侧边栏模块名称没有同步加入 i18n 资源；交接清单类别还一度把翻译后的显示文字当作业务值使用。

## 修复

- 补齐简体中文、繁体中文、英文三套翻译。
- 将页面静态文字、动态状态、操作反馈、导出表头和统计卡片统一改为读取 i18n。
- 为侧边栏 `adminTenantDirectory` 增加“租客管理 / Tenant Management”模块名称映射。
- 交接清单改为“稳定业务值 + 本地化显示名称”，避免切换语言后保存不同的数据值。
- 本地化脚本支持按文件执行，并清理旧机器翻译中的异常重复标点。

## 验证

- 目标文件 ESLint 检查通过。
- i18n 覆盖回归测试通过（3/3）。
- Vite 生产构建通过。
