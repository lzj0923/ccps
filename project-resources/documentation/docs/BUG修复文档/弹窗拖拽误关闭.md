# 弹窗拖拽误关闭

## 问题现象

在日常运营中心等弹窗内从右向左拖选文字或拖动鼠标，若在弹窗外的遮罩区域松开，弹窗会被误判为点击遮罩并关闭，返回上一层界面。

## 根因

工作台弹窗使用 `click.self` 监听遮罩关闭。浏览器在“弹窗内按下、遮罩上松开”的拖拽过程中可能合成一次以共同祖先遮罩为目标的点击事件，导致关闭逻辑被误触发。

## 修复内容

- 将工作台内 5 个同类弹窗的遮罩关闭触发由 `click.self` 改为 `pointerdown.self`。
- 现在只有鼠标或触控的按下起点就在遮罩上时才会关闭。
- 从弹窗内容区开始拖拽，即使在遮罩上松开也不会关闭。
- 保留直接点击遮罩关闭及右上角关闭按钮的原有功能。

## 验证结果

- 新增回归测试：`frontend/tests/admin-modal-backdrop-drag.test.mjs`。
- 工作台相关测试共 51 项通过。
- 前端生产构建通过。
