# Meta 资料删除网址无效 - 修复报告

## BUG描述
- 页面/功能：Meta 应用基本设置中的“用户资料删除指示网址”。
- 操作步骤：填写 `/data-deletion.html` 公网地址并保存。
- 期望结果：Meta 能访问公开的资料删除说明。
- 实际结果：Meta 提示网址无效，后端返回 HTTP 404。

## 复现步骤
1. 启动 CCPS 后端。
2. 请求 `http://127.0.0.1:8080/data-deletion.html`。
3. 确认响应为 HTTP 404。

## 根因分析
- 表象：Meta 不接受资料删除说明网址。
- 根因：后端静态资源目录中不存在 `data-deletion.html`。

## 修复方案
- 新增中英文资料删除说明页面。
- 明确申请方式、身份验证、删除范围、依法保留范围、处理期限和联系邮箱。
- 复用现有隐私政策样式，确保桌面端和移动端均可阅读。

## 单元测试
- 测试文件：`StaticCompliancePagesTest.java`
- 测试内容：确认静态资源存在，并包含删除申请主题、联系邮箱、期限及英文标题。

## 手动验证步骤
1. 重启后端。
2. 打开 `/data-deletion.html`。
3. 确认返回 HTTP 200，页面可公开访问。
4. 将完整 HTTPS 公网地址填写到 Meta。

## 影响范围
- 直接影响：Meta 用户资料删除说明网址。
- 间接影响：无；未修改业务接口和数据库。
