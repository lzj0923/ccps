# 运营总览“添加费用”按钮无可见反馈

## 问题现象

在“租房流程 → 日常运营中心 → 运营总览”点击“添加费用”后，当前视口没有明显变化，用户会认为按钮无法点击。

## 复现与根因

真实页面复现确认：点击事件正常触发，费用表单也正常创建，但表单被插入到可滚动内容区顶部。浏览器保留了点击按钮附近的滚动位置，新表单因此位于当前视口上方。

## 修复内容

- 为运营中心滚动容器增加模板引用。
- 当任一运营内联表单打开时，等待 DOM 更新后将内容区滚动到顶部。
- 自动聚焦表单第一个可操作字段，让用户立即看到并可开始录入。
- 该处理同时覆盖添加费用、新增开支等同类内联表单。

## 验证结果

- 专用回归测试：`node --test frontend/tests/admin-operations-add-charge-visibility.test.mjs`，1/1 通过。
- 前端生产构建：`npm --prefix frontend run build`，通过（仅保留原有大分包提示）。
- 真实页面验证：智慧小区 101 → 日常运营中心 → 运营总览 → 添加费用；点击后立即显示“添加运营费用”，内容区滚动位置归零，焦点落在“费用类型”下拉框。
