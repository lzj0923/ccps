# 租客与业主手机号缺少国家区号及格式校验 - 修复报告

## BUG描述

- 页面/功能：管理员端租客目录、业主管理、房产流程中心及房产详情。
- 操作步骤：填写 `100` 作为电话，勾选 WhatsApp 自动催收及同意确认后保存。
- 期望结果：页面在发起保存请求前提示号码格式错误。
- 实际结果：租客主资料先被保存，WhatsApp 授权接口随后拒绝号码，页面只显示笼统的操作失败提示。

## 复现步骤

1. 打开租客目录并编辑租客。
2. 电话填写 `100`。
3. 勾选 WhatsApp 自动催收及租客同意确认。
4. 点击保存，页面发起请求后显示操作失败。

## 根因分析

- 表象：启用 WhatsApp 自动催收后保存失败，但用户看不到具体号码错误。
- 根因：旧表单只有 `required` 和长度限制，没有国家/地区选择及号码规则校验；租客资料保存与 WhatsApp 授权为两个连续请求，错误号码直到第二个请求才被后端发现。
- 定位过程：检查租客表单、请求顺序及 `WhatsAppPhoneNumbers` 后端校验，确认 `100` 不满足 E.164 的 8～15 位有效国际号码要求。

## 修复方案

- 修改 `frontend/src/components/AdminTenantDirectoryWorkspace.vue`：
  - 增加国家/地区及区号选择。
  - 将本地号码转换为 E.164 后再提交。
  - 在输入框失焦及保存前校验，并显示具体中文提示。
  - 校验失败时不发起租客资料或 WhatsApp 授权请求。
- 修改 `frontend/src/components/AdminOwnersWorkspace.vue`、`AdminPropertyProcessWorkspace.vue` 和 `AdminPropertyDetailWorkspace.vue`：
  - 业主手机号统一使用国家/地区加本地号码输入，默认选择马来西亚 `+60`。
  - 新增及编辑均在提交前验证，并保存为 E.164 完整号码。
  - 页面明确提示完整号码同时是业主登录账号。
- 新增 `frontend/src/utils/tenantPhone.js`：使用 `libphonenumber-js/min` 解析、校验及拆分号码。
- 修改租客及业主请求 DTO：后端再次要求号码使用 E.164 格式，防止绕过前端。
- 修改 `AdminAccountService` 和 `AdminOwnerService`：编辑业主手机号时，在同一事务内同步修改登录用户名和账号联系电话；重复号码会拒绝整次保存。
- 修改 `frontend/src/services/propertyApi.js`：补充号码错误的中文提示。

## 单元测试

- `frontend/tests/tenantPhone.test.mjs`
  - 拒绝原问题中的三位号码 `100`。
  - 验证中国和马来西亚本地号码可转换为 E.164。
  - 验证所选国家与国际号码不一致时被拒绝。
  - 验证编辑已有 E.164 号码时能正确拆分。
  - 验证未启用 WhatsApp 时电话号码可以为空。
- `backend/src/test/java/com/ccps/backend/dto/AdminTenantCreateRequestValidationTest.java`
  - 后端拒绝 `100`，接受合法 E.164 及可选空值。
- `AdminOwnerPhoneValidationTest`、`AdminAccountServiceTest` 和 `AdminOwnerServiceTest`
  - 验证业主号码格式、登录账号同步及重复登录账号拦截。
- 测试结果：前端号码测试 5 项、后端专项测试 25 项全部通过；前端生产构建通过。

## 手动验证步骤

1. 刷新租客目录并打开新增/编辑租客。
2. 选择“中国大陆 +86”，输入 `100`，离开输入框，确认出现格式错误。
3. 点击保存，确认弹窗保持打开且没有发起保存请求。
4. 输入 `138 0013 8000`，确认错误消失并可保存为 `+8613800138000`。
5. 选择“马来西亚 +60”，输入 `012-345 6789`，确认可保存为 `+60123456789`。
6. 新增业主时确认默认选择“马来西亚 +60”，输入有效号码后保存。
7. 修改已有业主手机号，确认旧号码不再作为登录用户名，新完整号码可以配合原密码登录。
8. 输入已被其他账号使用的号码，确认业主资料和登录账号都不会被部分更新。

## 影响范围

- 直接影响：租客及业主新增、编辑，WhatsApp 自动催收授权，以及业主手机号登录。
- 登录影响：业主手机号被修改并保存后，登录用户名同步变为新的 E.164 完整号码，密码不变。
- 间接影响：联系人号码统一为国际 E.164 格式，便于 WhatsApp 发送和账号唯一性判断。
- 回归测试结果：通过。
