# 整租房产缺少出租空间选项 - 修复报告

## BUG描述
- 页面/功能：租房流程 → 建立租约 → 出租空间。
- 操作步骤：新建一套整租房产后，进入租房流程并打开“建立租约”。
- 期望结果：下拉框显示“整套房产”。
- 实际结果：下拉框为空，无法选择出租空间或保存租约。

## 复现步骤
1. 新建“智慧小区 101”，出租模式保持 `whole_unit`。
2. 进入租房流程并打开“建立租约”。
3. 查询该房产的出租空间，结果为 0 条；前端只展示 active 的 `whole_unit` 空间，因此下拉框为空。

## 根因分析
- 表象：整租房产没有可选的“整套房产”出租空间。
- 根因：历史迁移脚本会为已有房产补建 `WHOLE` 空间，但新增房产逻辑只写入 `units`，没有同步创建默认出租空间。
- 定位过程：数据库确认房产 `rental_mode=whole_unit`，但 `rental_spaces` 中没有对应记录；前端筛选逻辑本身正确。

## 修复方案
- 修改 `AdminOwnerService` / `AdminOwnerMapper`：创建房产时在同一事务内建立默认 `WHOLE` 出租空间。
- 修改 `AdminRentalSpaceService` / `AdminRentalSpaceMapper`：加载出租空间时幂等补齐历史漏建的 `WHOLE` 空间。
- 切换回整租模式时同样确保默认空间存在。
- 已为“智慧小区 101”补建 active 的“整套房产”空间。

## 单元测试
- 测试文件：`AdminOwnerServiceTest`、`AdminRentalSpaceServiceTest`。
- 测试用例：新建房产同步创建整租空间；加载出租空间时修复缺失的整租选项。
- 测试结果：相关测试全部通过。

## 手动验证步骤
1. 刷新租房流程页面。
2. 选择“智慧小区 101”。
3. 打开“建立租约”。
4. 确认“出租空间”下拉框出现“整套房产”。

## 影响范围
- 直接影响：房产新建、出租空间加载、切换整租模式。
- 间接影响：建立租约时的出租空间选择。
- 回归测试结果：完整后端测试共 271 项，269 项通过；2 项既有错误来自缺失
  `contract-templates/owner-tenancy-agreement-template.docx`，与本次修改无关。
