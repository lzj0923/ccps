# 租约生成排版错位与手机文件名乱码

## 问题表现

- 交接清单项目较多时，文字被表格横线穿过，房间分类被拆到不同页面。
- 合同第 10.17 条在原始模板中被拆成两页，阅读时上下文断开。
- 中文租约文件名在部分手机浏览器中显示为 `=_UTF-8_Q_...` 编码文本。

## 复现与原因

- 使用 86 条标准交接项目生成租约，能够稳定复现表格错位。
- 清单超过 60 条后被压缩为 12.5pt 行高，但文字基线仍按较高行距计算，导致文字落在横线上；续页可用区域不足又造成分类拆页。
- 第 10.17 条的断页来自固定 PDF 模板本身，生成程序此前直接保留了该断页。
- 下载响应只发送 MIME encoded-word 形式的中文文件名，部分移动端不会正确解析。

## 修复内容

- 重新计算清单行高、文字基线和续页可用区域，长清单不再压线。
- 按房间分类分页，标准清单中的同一分类保持在同一页。
- 将第 10.17 条完整排到下一页，并保留后续第 11 条标题和正文。
- 下载响应同时提供 ASCII 兼容文件名和 RFC 5987 UTF-8 文件名，兼容手机端中文显示。

## 验证结果

- 通过 86 条交接项目的生成测试与逐页渲染检查。
- 通过租约正文跨页、交接清单分类完整性及中文文件名专项测试。
