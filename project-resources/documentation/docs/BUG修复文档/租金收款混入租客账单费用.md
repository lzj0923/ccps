# 租金收款混入租客账单费用 - 修复报告

## BUG描述

- 页面/功能：租房流程 → 日常运营中心。
- 操作步骤：在运营总览点击“添加费用”并保存，再进入“租金收款”。
- 期望结果：租金收款只显示租金；水电费、管理费等租客账单费用单独管理，名称应使用业务中文。
- 实际结果：账单费用混在租金列表内，主标题取用户说明，副标题直接显示 `maintenance · tenant` 等内部枚举。

## 复现步骤

1. 选择智慧小区 101，进入日常运营中心。
2. 打开租金收款页签。
3. 可看到租金下方同时出现说明为 `101`、`1` 的费用记录，以及 `maintenance · tenant`、`utilities · tenant`。

## 根因分析

- “添加费用”实际写入 `rent_invoice_items`，属于当前租约的租客账单费用。
- 前端将租金和其他账单费用渲染在同一个“租金收款”内容区，没有按业务用途分栏。
- `rent_invoices.amount_due` 已包含附加费用，但页面仍把它整体标记为“租金”，同时又重复列出费用项目。
- 费用行直接展示 `chargeType`、`payer` 内部枚举，并把自由填写的 `description` 当主标题。

## 修复方案

- 新增独立“租客账单”页签，承载水电费、管理费、维修转收费和其他杂费。
- “租金收款”只显示扣除账单费用后的纯租金金额和租金记录。
- 费用主标题改为本地化费用类型；用户输入改为带“说明”前缀的备注，承担方同步本地化。
- 入口和表单统一改为“新增账单费用 / 新增租客账单费用”，明确保存位置。
- 新增账单费用成功后自动切换到“租客账单”页签。

## 单元测试

- 测试文件：`frontend/tests/admin-operations-rent-charge-separation.test.mjs`
- 覆盖：独立页签、纯租金金额、本地化类型与承担方、禁止裸露内部枚举。
- 结果：与原“添加费用可见性”测试合计 4/4 通过。

## 手动验证步骤

1. 打开智慧小区 101 的日常运营中心。
2. 进入“租金收款”，确认只显示 RM 5483.87 租金，不再出现 10 元和 100 元费用行。
3. 进入“租客账单”，确认两笔费用分别显示为“维修转收费”和“水电费”。
4. 确认说明显示为“说明：101 / 1”，承担方显示为“租客”，不再出现英文枚举。
5. 新增一笔账单费用，确认保存后自动进入“租客账单”。

## 影响范围

- 直接影响：日常运营中心的租金收款、租客账单、账单费用表单及中英繁文案。
- 数据影响：不迁移、不删除现有费用或收款数据，只调整展示分区和金额口径。
- 回归结果：专项测试通过，前端生产构建通过。
