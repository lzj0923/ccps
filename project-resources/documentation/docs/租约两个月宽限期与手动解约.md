# 租约两个月宽限期与手动解约

## 业务规则

- 租约到期后不立即自动解约，继续保留为有效租约，方便行政人员确认口头续约。
- 宽限期为两个日历月，自动解约日为“原租约结束日期 + 2个月”。例如租约在 2026-01-31 结束，自动解约日为 2026-03-31。
- 宽限期内可以正常办理续约，也可以由管理员手动解约。
- 宽限期内不生成超出原租约结束月份的租金账单，房源仍保持占用，避免在续约未确定时被重复出租。
- 到达自动解约日仍未续约时，系统把租约状态改为已结束；若房源没有其他有效租约，则恢复为可出租。

## 手动解约

在“租客与租金”选择租约后，可点击“手动解约”，填写：

- 实际结束日期
- 解约原因（租约到期后解约或提前解约）
- 解约备注

提交后租约立即结束，未来未缴的租金账单会移除；已付款或部分付款账单不会被删除。

## 自动任务

系统每日生成当月租金账单时检查已满宽限期的租约；进入租客与租金页面加载资料时也会补做检查，避免定时任务中断造成状态遗漏。

## 验证

- 后端测试覆盖“结束日期满两个日历月当天自动解约”、房源状态恢复及审计记录。
- 前端测试覆盖宽限期提示、手动解约弹窗、解约原因与接口调用。
