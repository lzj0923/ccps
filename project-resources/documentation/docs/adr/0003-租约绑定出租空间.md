# ADR 0003：租约绑定出租空间

- 状态：已接受
- 日期：2026-08-10

## 背景

同一套房产既可能整租，也可能按房间合租。直接允许同一房产存在多份重叠租约，无法判断哪些租约真正冲突，也会让账单、押金、附件和催缴归属不清。

## 决策

在房产下建立“出租空间”。每套房产固定有一个“整套房产”空间；启用合租后可增加多个房间空间。每份租约必须绑定一个出租空间。

- 整套租约与该房产任何房间租约互斥。
- 不同房间可在同一期间分别出租。
- 同一房间的租期不可重叠。
- 租金账单、押金、附件、签约和催缴继续按租约独立处理。
- 日常运营与附件签约必须先选择具体出租空间和租约，禁止默认把操作记到第一份租约。
- 合租公共费用可按当月实际在租房间均分，分摊结果分别写入各租约账单并保留来源标记。
- 合租界面按出租空间自动汇总总房间、已出租、仍可出租和出租进度；房产列表的“出租中”仅表示至少存在一份有效租约。

## 影响

既有房产自动获得“整套房产”空间，既有租约迁移至该空间，历史财务数据不拆分。公共费用必须显式分摊到各租约，不能重复计入房产总账。
