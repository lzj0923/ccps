# ADR 0004：统一资金确认与双日期权威

- 状态：已接受
- 日期：2026-08-25

## 背景

租金、押金、预备金、维修和普通收支曾在各自模块直接确认金额或修改日期，导致确认权限分散、余额口径不一致，且财务记录难以追溯来源单据。

## 决策

“财务确认”是所有金额由待确认转为已确认的唯一外部入口。来源模块只建立或修改待确认事项并上传凭证；财务确认同时确定 `transaction_date`（财务入账日期），收款类另行确定 `receipt_date`（实际收款日期），两者不得合并。中央确认服务按资金类型调用来源适配器，在一个事务内完成状态、余额、账单、关联流水、审计和通知。所有财务列表通过既有外键关系解析 `sourceType/sourceId`，保留从财务记录到来源单据的追溯关系。已确认记录必须先由财务退回，来源模块才能修改。

## 影响

旧的预备金审核、租客/业主确认、房产流程确认和已确认租金维护入口停止办理；租金确认 HTTP 入口迁入财务命名空间。业务提交日期只作为核对资料，最终余额及报表以财务入账日期为准。历史数据不重算余额，后续确认全部执行统一状态机和双日期规则。
