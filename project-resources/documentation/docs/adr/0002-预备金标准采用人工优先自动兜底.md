# 预备金标准采用人工优先、自动兜底

## 状态

已接受（2026-08-10）

## 决策

预备金账户同时保留“人工设置”和“系统自动”两种标准来源。已有大于零的最低标准视为人工设置并继续生效；没有人工设置的新账户默认使用系统自动标准。自动标准按“一个月租金 + 最近十二个月内业主承担的必要经营支出月均 × 三个月”计算，且最低不低于 RM 2,000。系统仍会为人工账户计算并展示建议金额，但不会覆盖人工金额，除非工作人员主动切回自动模式。

## 原因

单纯固定金额无法反映不同房产的租金与经营成本，而直接覆盖人工金额又可能违反合同或个别管理约定。人工优先、自动兜底既能让普通房产自动形成合理保障标准，也能保留特殊项目的人工控制权。

## 结果

预备金不足提醒以“有效预备金标准”为准。自动模式会随租金和支出变化定时更新；人工模式保持不变。系统自动计算只更新标准和提醒，不会自动充值、扣款或确认到账。
