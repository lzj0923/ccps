# CCPS 功能完成度清單

更新日期：2026-07-20

## 狀態定義

- **已完成**：已有管理界面，並已接入後端 API／資料庫，可完成主要操作。
- **未完成**：目前只有頁面或入口，尚未完成後端流程、資料同步或實際業務處理。

## 後續接入項目

下列項目需要外部系統資料或進一步的營運規則，目前不影響既有第一階段流程使用：

| 模組 | 目前狀態 | 尚待完成內容 |

| 報表排程與派送 | 手動產出、歷史與下載已完成 | 確認營運頻率、收件人及郵件設定後，增加定時產出與 Email 派送 |

## 建議開發順序

1. **SQL Account 現場接入**：取得目標版本及技術通道，用真實 Gateway 替換 CSV Gateway，保留既有批次、重試與稽核流程。
2. **報表排程與派送**：依實際月結／週報規則增加排程與收件人設定。
3. **自動提醒擴充**：目前已接入五種核心事件；後續可增加維修逾期及財務待確認事件。

## 驗收標準

- 三個模組均有可用的後端 API，而不是只可開啟頁面。
- 所有新增、修改、同步及匯出操作均有成功／失敗提示。
- 重要操作保留操作人、時間、資料範圍及錯誤記錄。
- SQL Account 在外部回執前不得顯示為已同步；現階段匯入檔只顯示為已匯出。
- 以現有資料庫資料驗證，不使用 `ADMIN Test`、`Test Tenant` 等測試名稱作為正式展示資料。
