# 房产交接清单设计

## 目标

为每套房产建立可维护的交接物品主清单。创建标准交屋报告时读取该清单，报告完成后把本次报告的物品、分类和最新数量同步回主清单。

## 规则

- 清单属于房产（owner unit），不是某一份报告。
- 清单项目可新增、修改、删除、排序和启用/停用。
- 新建交屋报告时复制当前清单到报告内容，业务填写本次数量、状况、备注和照片。
- 报告保存为草稿时不更新主清单。
- 报告标记为已完成并保存成功后，按报告内容回写主清单。
- 回写只更新物品名称、分类、排序和最新数量；本次状况、备注、照片只保留在报告快照中。
- 历史报告不会随着主清单变化而改变。
- 没有主清单项目时，报告仍可手动新增项目。

## 页面

房产详情二级菜单新增「交接清单」。表格按分类显示项目，支持新增、编辑、删除和排序。

## 数据

新增 `property_handover_checklist_items` 表，以 `owner_unit_id`、`category`、`item_name`、`default_quantity`、`sort_order`、`enabled` 保存主清单；报告的 `content_json` 继续保存当次快照。
