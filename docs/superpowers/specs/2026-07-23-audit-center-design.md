# 操作审计中心设计

## 目标

让管理人员无需查询数据库，即可追查重要资料异动：谁在何时对哪一笔资料做了什么，以及修改前后的内容。

## 第一版范围

- 后台新增「操作审计」入口。
- 支援按日期、操作人员、操作类型、关键字筛选，并分页浏览。
- 每笔记录可展开查看修改前／后资料。
- 使用既有不可编辑的 `audit_logs` 资料；新纳入服务商的新增、修改与停用。
- 沿用既有管理员登录保护；不在本次加入文员分级权限或审计记录删除功能。

## 边界

- 审计记录是证据，不提供编辑或删除操作。
- 历史上未写入审计表的动作无法事后还原；页面只显示实际已有的记录。
- 只记录重要的资料异动，不记录一般查看页面。
