# 租赁合约 PDF 自动生成设计

## 目标

使用客户提供的 `Conlay 40-12 TA.pdf` 作为只读模板，在不改动条款、图片、分页和原版式的前提下，自动带入租约资料并输出新的 PDF。

## 方案

采用 PDF 套版覆盖：后端以原 PDF 为底稿，清除样本中的动态资料区域，再在固定坐标写入新资料。原模板的正文条款和交接照片不重新生成，也不转换为 Word。

## 自动带入字段

案件编号、协议日期、业主姓名／证件／地址、租客姓名／证件／电话／地址／电邮、物业地址、租期、开始日、结束日、月租、缴租日、付款银行资料、预付租金、押金、水电押金、用途、续租选项及特别条件。

## 输出规则

- 返回 `application/pdf`，文件名使用 `Tenancy-Agreement-{单位或案件编号}.pdf`。
- 字段过长时自动缩小字体，但不超过预设最小字号。
- 未提供的字段保持空白，不使用样本中的真实资料。
- 模板文件只读，任何生成请求都产生独立副本。

## 验证

服务测试验证 PDF 可打开、页数保持 22 页、样本姓名不残留、关键新字段出现；接口测试验证 PDF Content-Type 和 `.pdf` 文件名；前端测试验证租赁合约按钮调用 PDF 下载并显示 PDF 文案。
